How the agent decides

          
c(x) = max softmax(z(x) / T)

          
    
            
  • ABSTAIN when c(x) is below τ. A person decides.
    • 
            
  • QUEUE when the agent is confident the review is negative.
    • 
            
  • PASS when it is confident the review is not negative.
    • 
          

          
If the model fails, the answer is ABSTAIN: a review is never accepted without a prediction.
